# 재건축 수익계산기 v8

서울 주요 재건축 4개 단지(신반포2차·압구정5구역·대치 은마·잠실주공5단지)를
전용 84㎡ 배정 기준으로 비교하는 투자수익 계산기입니다.

- 프롭테크비지니스 조별과제 (단국대 부동산건설대학원, 2026년 2학기)
- 총투자금: 자체 산정(실거래 매수가 + 분담금 + 취득·보유비용) / 민간 분석값 전환
- 연환산 수익률(IRR) + 사업단계 요구수익률 → 위험조정 초과수익, 순위 기준 전환
- 단계별 기대가격 경로, 실투자금(갭), 신뢰도 등급(C~A+)
- 민감도: 토네이도, 2변수 히트맵, 상승률별 추이
- 전체 일괄 / 단지별 개별 가정 조정
- **단지 추가(범용)**: 서울 25개 구 어느 단지든 검색 → 평형별 실거래·주변 신축 84㎡ 후보 자동 조회(`/api/district`) → 사업단계·분담금만 입력해 비교 목록에 추가. 브라우저에 저장
- **시세 흐름 비교**: 단지를 골라 색상별로 겹쳐 보기 — 과거 12개월 실거래 월 중위(실선) + 사업단계별 기대가격 경로(점선) → 입주. 84㎡ 환산가/대표 평형 매매가 전환, 단지 쌍별 현재·종료 시 격차와 역전 시점 자동 분석
- **재건축부담금(재초환)**: 자동 추정(기본)·직접 입력·미반영 전환. 재건축초과이익 환수에 관한 법률(2024.3.27 시행) 구조 단순화 — 8천만원 면제, 5천만원 구간 10~50% 누진, 개시시점 조합설립인가일(10년 상한), 공시가격 현실화율·정상상승률·1세대1주택 장기보유 감면 조정 가능
- **비교 대상 관리**: 기본 4개 단지는 숨기기/다시 표시, 추가 단지는 개별·전체 삭제(확인 후). 숨김·추가 상태는 브라우저에 저장
- **정비사업 공식 현황(v8)**: 서울특별시 도시정비사업 통계(서울 열린데이터광장 OA-22856, `TbSeoulRedevStatus`)를 `/api/projects`로 조회 → 단지별 추진단계·인가일 타임라인·기존/건립 세대 표시, 앱 단계와 다르면 안내. 추가 단지는 지번(법정동+본번)으로 정비구역 자동 매칭 → 단계·조합설립인가일(재초환 개시시점)·세대수 자동 입력. API 미연결 시 내장 스냅샷(`public/seoul_projects.json`, 2026.6 기준, 아파트 재건축 166개 구역)
- 시공사: 통계 항목에 없어 언론 보도·조합 공지로 확인한 값과 출처 표기
- 신축 시세·대표 매물 매수가: 국토교통부 실거래가 API 실시간 조회(`/api/trades`), 실패 시 2026.8 수집 고정값

## 배포 설정 (Vercel)

- Settings → Environment Variables 에 `MOLIT_API_KEY` = 공공데이터포털 **Decoding** 인증키 등록 후 Redeploy
- (선택) `SEOUL_API_KEY` = 서울 열린데이터광장 일반 인증키 — 없으면 내장 스냅샷 사용
- 인증키는 코드·저장소에 넣지 않습니다.
- 함수 리전 서울(icn1), 결과 6시간 캐시
