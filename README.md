# 재건축 수익계산기

서울 주요 재건축 4개 단지(신반포2차·압구정5구역·대치 은마·잠실주공5단지)를
전용 84㎡ 기준으로 비교하는 투자수익 계산기입니다.

- 프롭테크비지니스 조별과제 (단국대 부동산건설대학원, 2026년 2학기)
- 신축 시세·사업기간·연 상승률을 사용자가 조정하면 수익률과 순위가 즉시 재계산됩니다.
- 외부 API를 사용하지 않으며, 데이터는 코드에 내장되어 있습니다.

## 검증 (기본값: 시세 0% / 기간 0년 / 상승률 3.5%)

| 순위 | 단지 | 연환산 수익률 |
|---|---|---|
| 1 | 잠실주공5단지 | 6.23% |
| 2 | 신반포2차 | 5.50% |
| 3 | 압구정5구역 | 5.24% |
| 4 | 대치 은마 | 4.88% |

## 로컬 실행 (선택)

```
npm install
npm run dev
```
