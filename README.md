# 재건축 수익계산기 v5

서울 주요 재건축 4개 단지(신반포2차·압구정5구역·대치 은마·잠실주공5단지)를
전용 84㎡ 배정 기준으로 비교하는 투자수익 계산기입니다.

- 프롭테크비지니스 조별과제 (단국대 부동산건설대학원, 2026년 2학기)
- 총투자금: 자체 산정(실거래 매수가 + 분담금 + 취득·보유비용) / 민간 분석값 전환
- 연환산 수익률(IRR) + 사업단계 요구수익률 → 위험조정 초과수익, 순위 기준 전환
- 단계별 기대가격 경로, 실투자금(갭), 신뢰도 등급(C~A+)
- 민감도: 토네이도, 2변수 히트맵, 상승률별 추이
- 전체 일괄 / 단지별 개별 가정 조정
- **단지 추가(범용)**: 서울 25개 구 어느 단지든 검색 → 평형별 실거래·주변 신축 84㎡ 후보 자동 조회(`/api/district`) → 사업단계·분담금만 입력해 비교 목록에 추가. 브라우저에 저장
- 신축 시세·대표 매물 매수가: 국토교통부 실거래가 API 실시간 조회(`/api/trades`), 실패 시 2026.8 수집 고정값

## 배포 설정 (Vercel)

- Settings → Environment Variables 에 `MOLIT_API_KEY` = 공공데이터포털 **Decoding** 인증키 등록 후 Redeploy
- 인증키는 코드·저장소에 넣지 않습니다.
- 함수 리전 서울(icn1), 결과 6시간 캐시

## 검증

| 항목 | 결과 |
|---|---|
| API 파서 ↔ 저장된 실제 응답 XML 72개(2025.9~2026.8) | 22개 항목 중 21개 엑셀과 일치. 청담르엘은 분양권 1건 혼입을 바로잡아 9→8건 |
| 계산엔진 ↔ 4단지_단계별_시간가치_투자비교_v1.xlsx | 단계별 기대가격 전 구간 일치, IRR 차이 0.02%p 이내(일수 계산 차이) |
| 자체 산정 기본값 IRR ↔ Python 독립 계산 | 6.72 / 6.02 / 5.40 / 4.69% 일치 |
| 단지 추가 API ↔ 저장된 실제 응답(서초·강남·송파) | 은마·신반포2·주공5단지 평형별 건수·중위가 엑셀과 일치 |
| 단지 추가 화면 → 계산 결과 ↔ Python 독립 계산 | 일치, 기존 4개 단지 수치 불변 |
| 민간 분석값 모드 | 잠실5 6.24 / 신반포2 5.50 / 압구정5 5.24 / 은마 4.88% |

## 데이터 출처

- 실거래: 국토교통부 매매·분양권전매(입주권) 실거래가 API, 최근 12개월, 해제거래 제외
- 분담금: 정비계획 결정 고시(신반포2·압구정5 추정), 조합 발표(은마·잠실5)
- 민간 분석 현재가치·소요시간·총투자금: 민간 부동산 분석자료(호가·임장 기반, 2026.10)
